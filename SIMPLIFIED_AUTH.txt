COMMON ISSUES & SOLUTIONS
================================================================================

ISSUE: "Authentication failed" keeps showing
WHAT WENT WRONG: Old version had RecaptchaVerifier issues
SOLUTION: 
   1. Clear browser cache (Chrome Settings > Clear Data)
   2. Close browser completely
   3. Reopen app - should show new login screen
   4. Try signing up fresh

ISSUE: Can't remember password
SOLUTION:
   Currently no "Forgot Password" feature
   Workaround: Create new account with different email
   Contact: khanmoazzam883@gmail.com for manual reset

ISSUE: Email shows "already in use" but can't login
WHAT: Account exists but password is wrong
SOLUTION:
   1. Try "Create one" to see if email already exists
   2. If error shows "already registered", then use Login screen
   3. Try password again carefully
   4. If still fails, contact support

ISSUE: Password too weak error
SOLUTION: Use password with 6+ characters
   Good examples:
   • MyPharmacy2024
   • Pass@123
   • SecurePass99
   
   Avoid: 123, abc, password (too common)

ISSUE: Email shows invalid
SOLUTION: Use proper email format
   Good examples:
   • moazzam@example.com
   • your.name@gmail.com
   • pharmacy@business.com
   
   Avoid: @, moazzam@ (no domain), moazzam.com (no @)

WHAT HAPPENED TO PHONE OTP?
================================================================================

WHY REMOVED:
1. RecaptchaVerifier was causing "authentication failed" errors
2. reCAPTCHA setup required Firebase console configuration
3. Phone OTP is complex and not essential for pharmacy app
4. Email/password is simpler, more reliable, more stable

BENEFITS OF REMOVING PHONE OTP:
✓ No reCAPTCHA errors
✓ No "authentication failed" on startup
✓ Simpler login process
✓ Works everywhere (no SMS delivery issues)
✓ Easier to remember email/password
✓ No SMS costs to worry about
✓ Data still persists across sessions

IF YOU NEED PHONE LOGIN LATER:
- Contact: khanmoazzam883@gmail.com
- We can add it back after stabilizing email auth
- Or create separate phone-auth version
