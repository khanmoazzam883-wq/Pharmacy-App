# PharmaCare - Pharmacy Management System

This repository contains the high-fidelity UI designs and frontend code for **PharmaCare**, a mobile-first pharmacy management application designed for clinical precision and operational efficiency.

## Overview

PharmaCare streamlines the daily workflows of pharmacists and pharmacy technicians. The interface is built with a focus on information hierarchy, safety alerts, and rapid task execution.

## Core Screens

### 1. Pharmacy Dashboard
A central hub for real-time operations.
- **Progress Tracking:** Monitor daily order completion.
- **Quick Actions:** Instant access to New Rx, Scanning, and Patient lookup.
- **Urgent Alerts:** Immediate visibility into interaction flags and prior authorizations.

### 2. Prescription Queue
Manage the lifecycle of medication orders.
- **Workflow Stages:** Filter by active orders or those needing verification.
- **Promise Times:** Color-coded indicators for on-time and overdue fills.
- **Verification Status:** Clear visual cues for 'Ready' vs 'Verifying'.

### 3. Inventory Manager
Real-time stock and supply chain oversight.
- **Critical Alerts:** Automated notifications for low stock and expiring medications.
- **Restock Flow:** Rapid replenishment tools.
- **NDC Lookup:** Search by medication name, NDC, or manufacturer.

### 4. Patient Directory
Comprehensive clinical profiles.
- **Safety First:** Prominent visual flags for severe allergies and drug interactions.
- **Medication History:** At-a-glance view of recent and active prescriptions.
- **Communication:** Quick-access messaging and calling for patient outreach.

## Design System: Clinical Precision
- **Typography:** Inter (Sans-serif) for high legibility in clinical settings.
- **Color Palette:**
  - `Primary (#0b3c5d)`: Trustworthy deep blue for navigation and structure.
  - `Surface (#f8f9ff)`: Clean, clinical background.
  - `Alerts`: High-contrast red and amber for critical safety notifications.
- **Components:** Modular cards, sticky app bars, and large touch targets designed for use on mobile devices during busy shifts.

## Tech Stack
- HTML5 / CSS3
- Tailwind CSS (Utility-first styling)
- Google Material Icons
