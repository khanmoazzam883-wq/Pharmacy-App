STEP 3: FIRESTORE SECURITY RULES
================================================================================

The app uses ENHANCED security rules for v2.0:

1. Go to Firebase Console → Firestore Database → Rules

2. Replace existing rules with:

---BEGIN RULES---

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // User's main document - only they can read/write
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
      
      // Subcollections for audit logs, stock movements, etc.
      match /{document=**} {
        allow read, write: if request.auth != null && request.auth.uid == uid;
      }
    }
  }
}

---END RULES---

3. Publish rules

NOTE: These rules ensure:
   ✓ Users can only access their own data
   ✓ No user can read another user's inventory, purchases, or sales
   ✓ All data is encrypted in transit
   ✓ Backend validation will be added in future versions

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "OTP not received"
SOLUTION: 
   1. Check phone has SMS (cellular) enabled
   2. Wait 30 seconds and tap "Resend OTP"
   3. If still not working, use Email/Password login instead

PROBLEM: "Wrong OTP error"
SOLUTION:
   1. Re-enter the 6-digit code carefully
   2. Tap "Change Number" to try again
   3. OTP expires after 10 minutes

PROBLEM: "Email already registered"
SOLUTION:
   1. Use same email you used in v1
   2. If forgot password, you'll need password reset (contact support)

PROBLEM: "Data not loading"
SOLUTION:
   1. Check internet connection
   2. Try logout and login again
   3. Close app, clear cache, reopen
   4. If using PWA app icon, uninstall and reinstall

PROBLEM: "Can't upload to GitHub on mobile"
SOLUTION:
   1. Use desktop website mode in Chrome:
      → Menu → "Desktop site"
   2. Or use GitHub mobile app
   3. Or ask for help

PROBLEM: "Firebase errors in console"
SOLUTION:
   1. Check Firebase project "pharmadesk-c0ce3" is active
   2. Verify authentication methods are enabled
   3. Check Firestore security rules are published
   4. Connection errors are usually temporary

FIREBASE FIRESTORE DATA STRUCTURE (v2.0)
================================================================================

users/{uid}/
   ├─ profile (document) - name, email, pharmacy, phone, gstin
   ├─ items[] (array) - inventory items (v1 compat)
   ├─ suppliers[] (array) - suppliers list (v1 compat)
   ├─ customers[] (array) - customers list (v1 compat)
   ├─ purchases[] (array) - purchase records (v1 compat)
   ├─ sales[] (array) - sales records (v1 compat)
   ├─ meta (object) - counters, config
   ├─ schemaVersion (number) = 2
   ├─ auditLogs/ (collection) - NEW
   │  └─ action, entity, timestamp, summary, userId
   └─ stockMovements/ (collection) - NEW
      └─ movementType, itemId, quantity, date, reference

All v1 data is preserved in main document.
New v2 features use subcollections.
Automatic backward compatibility.
