================================================================================

   ✓ profile object
   ✓ meta counters
   ✓ All existing data loads automatically
   ✓ No data loss or migration required

ADDED: New Collections (Subcollections)
   
   /users/{uid}/auditLogs/
      ├─ userId: string
      ├─ action: string (SALE_CREATED, PURCHASE_CREATED, etc.)
      ├─ entity: string (sale, purchase, item, user, supplier)

      ├─ itemId: string
      ├─ batchId: string
      ├─ quantity: number

      ├─ referenceId: string (invoice/GRN number)
      ├─ date: ISO 8601
      ├─ userId: string
      └─ reason: string

================================================================================
KNOWN LIMITATIONS & NOTES
================================================================================

1. OCR Bill Scanning:
   Accuracy depends on bill photo quality.
   Best results: Clear, straight photo, good lighting.
   Manual edit available after extraction.

2. AI Assistant (v2.0):
   Uses local analytics, not external AI.
   Responds to: inventory, sales, purchases, stock value.
   Does not understand complex domain-specific questions.
   Future: Real AI backend will handle more questions.

3. Firestore Limits:
   50,000 reads/day (free tier).
   For 5 small pharmacies using daily: ~2,000 reads = 4% of quota.
   When exceeding: Switch to Blaze Plan ($0.06 per 100k reads).

4. Offline Mode:
   App works offline (reads cached data).
   Offline writes: Saved to localStorage, synced when online.
   Sync may take 10-30 seconds after connection restored.

5. Browser Support:
   Chrome/Firefox: Full support
   Safari: Full support (iOS 11+)
   Edge: Full support
   Internet Explorer: NOT supported
