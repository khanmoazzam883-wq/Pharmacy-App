TROUBLESHOOTING:
   
   Q: "Camera permission denied"
   A: 1. Grant camera permission in browser settings
      2. Or check phone Settings > Camera > [Browser]
      3. Or use file upload instead
   
   Q: "No camera found"
   A: 1. Device doesn't have camera
      2. Use file upload option instead
      3. Or take photo separately, then upload
   
   Q: "Permission popup doesn't appear"
   A: 1. Browser might have blocked camera
      2. Go to browser settings > Camera
      3. Reset permission for this site
      4. Reload page and try again
   
   Q: "Camera loads but capture fails"
   A: 1. Camera is already in use by another app
      2. Close other camera apps
      3. Try again
   
   Q: "OCR not extracting data properly"
   A: 1. Bill photo quality too low
      2. Try: Clearer photo, better lighting, straight angle
      3. Manually edit extracted fields before saving
      4. Or use file upload for better control
